# 长截图

1. 使用原有截图快捷键打开 mask，点击左下角 **滚动截图** 或按 **L** 进入长截图模式；再次点击或按 L 返回普通截图。
2. 框选需要滚动的内容区域，避开侧栏、视频和其他动态内容。固定标题栏和底部输入框可以包含在选区内：它们在长图中只保留一份（标题栏取第一帧，底栏取最后一帧）。在选区上方或下方留出约 452 个逻辑像素，或在左右留出约 312 个逻辑像素，供控制条显示。
3. mask 隐藏后，选区外侧显示约 2 个逻辑像素宽的蓝色高亮框，标出正在采集的区域。高亮框位于选区之外，不会进入长图，也不拦截鼠标（点击、滚轮直接作用于下方页面）；贴着屏幕边缘的一侧不绘制。在原窗口选区内向下滚动，每次保留一部分与上一帧相同的内容。页面移动时每次采样后只等待约 20 毫秒，静止时约 100 毫秒；Windows 上只读取选区并复用原生位图。控制条顶部的状态标签显示等待滚动、正在采集、已回滚、需要调整或已暂停。「长图预览」按面板宽度显示长图最新的底部内容，左侧窄条显示整张长图的缩略全貌；「当前选区」显示当前截取的内容，Tab 键可切换。下方显示结果尺寸、帧数和选区在屏幕上的位置示意。新拼接的内容约 120 毫秒内显示，当前选区约每 300 毫秒刷新一次。保持窗口位置、尺寸和显示缩放不变。
4. 滚动结束后点击 **完成**，或再次按截图快捷键（鼠标无需离开页面）。结果以贴图窗口打开，可使用已有的复制、保存和标注功能。初始显示会缩小以适应屏幕，保存的图像保留完整像素。长截图进行中按截图快捷键不会丢弃本次长截图，而是完成它。
5. 点击 **取消** 放弃本次长截图。控制条获得焦点时，也可使用 Esc 取消或 Enter 完成；焦点在原窗口时，按键仍由原窗口处理。

向上滚动不算失败：已拼接内容保持不变，状态显示「已回滚」，继续向下滚动即可从最后接受的位置接上；此时点击完成直接使用已拼接结果。如果当前帧连续多次没有稳定重叠或内容存在歧义，会保留最后成功的拼接结果并提示向上滚回一些，再缓慢向下滚动。“完成拼接”结束采集并使用已接收的结果，不会为确认结束而重新读取页面。如果最后一段未能加入，会暂停采集并明确提示：可点击“保留已拼接部分”打开已有结果，或点击“继续采集”补齐尾部；不会自动丢弃未拼接尾部并当作完整结果导出。

拼接按滚动位移匹配：先找出两帧之间原位不动的顶部和底部行（固定标题栏、输入框；允许光标闪烁、滚动条等少量变化），只在中间的滚动区域比较，并同时搜索向下和向上滚动。每个候选位移按文字／图像边缘和像素差异评分，采用最佳位移；只有其他非相邻位移几乎同样匹配时才判为歧义，因此相似的列表或消息布局也能靠不同的文字定位。匹配允许少量颜色和局部像素差异，并检查边缘，避免把空白背景当作有效重叠。鼠标移向控制条时的小块悬停变化不视为新增滚动帧。截取 ChatGPT 历史对话时，框选中间的对话列即可；顶部栏和底部输入框可以留在选区内。

当前限制：不按采集帧数限制长度，单边不超过 16,384 像素，总像素不超过 16 Mi；重叠比较有与选区大小成比例的计算预算。固定栏检测每侧最多占选区高度的三分之一。不支持自动滚动、横向拼接或跨显示器选区。选区覆盖整屏、没有控制条空间时会提示重新框选。

## 实现与验证边界

原生采集继续通过 rotor-platform 的 Windows/macOS API。rotor-runtime 管理采集和拼接工作线程，并发布带请求身份的事件；rotor-desktop 校验会话、管理窗口及结果显示，rotor-ui 提供操作界面。取消、重新截图、关闭控制条和退出应用都会停止本次采集，过期结果不会打开贴图。

自动化覆盖 mask 的 L 键和模式重置、选区裁剪与通道转换、拼接失败后的恢复、采集中取消、过期请求、控制条与选区不相交，以及长图记录的源坐标和完整像素范围。Windows/macOS 原生滚动交互、混合缩放与实际剪贴板粘贴仍需实机验收。
