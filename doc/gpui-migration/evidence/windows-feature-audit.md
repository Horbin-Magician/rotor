## F04 关闭与资源释放

核对发现原生搜索关闭没有发送旧版 hideWindow 的 release 请求，且共享核心 release 后仍保留查询结果分配。已在 `75429c5` 修复，[回归记录](windows-search-release.md) 包含修复前失败与修复后 18 项搜索测试通过的结果。

## P6 首发标注范围

计划要求首版不新增 redo，但原生工具栏和 Ctrl/Cmd+Shift+Z 曾提供用户级重做。已移除这些额外入口，保留普通撤销按钮和标注模式下的 Ctrl/Cmd+Z。

撤销快捷键现在仅在标注模式接管，Shift/Alt 组合不被当作撤销，非标注模式的组合可继续交给已配置的贴图按键。文字输入已有的 IME/编辑优先分支保留。

文档内部的 redo 保留给渲染/裁剪失败后的事务恢复，因此既有名称包含 redo 的底层测试仍有意义；它不意味着 UI 仍提供重做。14 项 UI 单测、native/UI 严格 clippy 通过，包含新的按键作用域测试及既有失败回滚测试。未将这些测试当作真实 IME 或鼠标验收。

## 尚需收口的保存交互

旧 QuickSettings 的编辑弹层本来就有保存按钮，原生的编辑保存本身不算增加步骤；但旧启停/删除直接提交，原生仍需全局保存。普通文本设置/快捷键的显式保存也与旧 watch 写入有差异，仍需按 UI-04 收口。不能为减少一步而把其他未完成草稿意外写入，后续须同时验证事务、输入和失败回滚。
