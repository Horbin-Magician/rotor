- 独立 `rotor-recovery.exe` 随 Windows 包交付，在 NSIS 更新后的重启入口启动 GUI。启动失败、提前退出或 30 秒内无就绪回执触发现有安装回退；正常回执后继续观察一秒。启动期外的一般运行期崩溃不在监控范围内。
