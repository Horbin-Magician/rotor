## 0. 第一优先级：UI 现代化美化（先于其余剩余任务）

2026-09-08 用户新增要求：**参考旧 UI 完成原生 UI 现代化美化，美观度和实用性均不得低于旧 UI。** 此任务排在所有剩余任务之前，所需旧 UI 取样与交互核对作为本任务的首步；不能只达到“功能可用”就进入后续收尾。

- [ ] **UI-01：建立旧 UI 对照。** 结合旧 Vue 页面、组件、主题样式和实际界面，整理各窗口的截图与典型操作流程，记录布局、信息密度、视觉层级、常用入口、快捷键和反馈方式。参考范围包括设置/概览/快捷操作/更新、搜索、翻译、截图遮罩、贴图工具栏、标注和 OCR。
- [ ] **UI-02：统一现代化视觉规范。** 在 GPUI + gpui-component 中统一字体层级、间距、对齐、颜色、图标、圆角、边框及阴影，覆盖浅色/深色/跟随系统、中英文和不同 DPI；保留旧 UI 有效的信息组织和操作习惯。
- [ ] **UI-03：逐模块完成界面美化。** 按上述完整范围落实布局和控件优化，补齐悬停、选中、焦点、禁用、加载、空结果、错误及成功反馈；长文案、窄窗口和缩放下关键内容与操作不能被遮挡或截断。
- [ ] **UI-04：保证实用性不退步。** 常用操作入口清楚、步骤不多于旧 UI，键盘操作和中文 IME 可用；搜索结果易扫描，翻译结果易阅读复制，截图/贴图工具不遮挡关键内容，设置分组和保存反馈明确。美化不能牺牲功能覆盖、对比度、点击区域、响应速度或低占用目标。
- [ ] **UI-05：完成新旧对照验收。** 使用相同内容、窗口尺寸、主题和 DPI，逐模块保存新旧截图与操作记录，核对视觉一致性、层级、留白、可读性及操作效率。逐项记录改进和差异，修复视觉或使用体验退步后再关闭本任务；编译通过、静态设计稿或单张首页截图不能代替实际界面验收。

交付：实际原生 UI 改动、统一视觉规范、逐模块新旧对照及验收记录，记录放在本目录 `evidence/` 下。视觉验收必须满足“美观度不低于旧 UI”，交互验收必须满足“实用性不低于旧 UI”；本任务通过后仍需完成后续双平台完整验收与性能测试。

2026-09-08 续作：已建立[源码对照与视觉规范](evidence/ui-modernization.md)，并实现设置左导航、主题卡片、固定保存区、概览和快捷操作第一批美化，native check/debug build 通过。实际窗口取样被用户 Esc 停止，尚未完成视觉验收；UI-01–UI-05 保持未关闭。

后续续作已完成搜索/翻译/截图/贴图与 OCR 第一批美化，取得旧壳七类实际截图及部分原生截图，并据旧 UI 修正主题、快捷键密度、快捷操作列表、引擎参数显示和翻译窗口高度。原生/共享业务测试与严格 clippy 通过；最后一轮桌面操作再次被用户 Esc 停止。原生概览索引详情、合成贴图恢复未出现的诊断、其余模块和同尺寸/DPI 对照仍待完成，详见 UI 证据。

## 4. 执行顺序和文档收口

1. 首先完成 UI-01–UI-05：参考旧 UI 进行现代化美化，以逐模块对照确认美观度和实用性均不低于旧 UI。
2. 稳定美化后的代码，补 Windows 原生交互及 macOS 编译/运行，修复发现的问题；同时补旧版导出和性能基线。
3. 选定递增版本，重新生成候选，完成双平台安装/升级/故障恢复与数据兼容演练。
4. 完成固定环境性能与长驻测试，达到 G8 及功能/性能门槛后执行 P9 目录和旧壳清理。
5. 对清理后的最终产物复验，更新逐项证据、正式发布流程与用户文档，再判定 G9。
