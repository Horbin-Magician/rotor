# 项目结构审阅与精简记录（2026-09-12）

本轮围绕整个 Cargo 工作区的依赖边界、调用关系和主要运行路径进行审阅，修改能确认用途、能保持现有行为、能用当前环境验证的部分。这里的结果不代表 Windows 实机或全部图形交互已经验收。

## 已实施

| 范围 | 发现与改动 |
| --- | --- |
| 搜索图标 | 删除原生 RGBA → PNG → Base64 → PNG 解码的中间传输。平台返回 RGBA，搜索结果通过 `Arc<RgbaImage>` 共享像素，界面复用已有的 RGBA/BGRA 转换。转换后释放结果中的原始像素，渲染缓存仍受 100 条搜索结果上限约束。 |
| 搜索匹配 | 用 `SearchQuery` 统一 Windows/macOS 的查询准备。每次查询只拆分一次通配符；ASCII 文件名复用小写缓冲区；索引中的拼音别名直接匹配。Unicode 文件名继续使用 Rust 的上下文小写规则。字符过滤掩码不再创建临时小写字符串。 |
| 搜索状态 | 删除 `SearchResult` 包装和只写不读的重复查询字段，保留实际分页缓存、查询标识、取消和索引释放行为。 |
| 运行时结构 | 设置命令、写入循环、合并及快捷键协调归入 `services/settings_worker.rs`；截图协调归入已有 `capture_worker.rs`；综合服务测试移入 `services/tests.rs`。`services.rs` 从 1819 行减至 924 行，测试代码是迁移而非删除，已有公共服务入口不变。 |
| 未使用接口 | 删除平台资料路径转发、两层临时目录转发、翻译器隐式读取全局配置的入口、未使用的默认快捷动作解析入口、未使用的配置全局锁引用入口、未使用的 `can_redo` 查询接口。实际重做功能保留。 |
| 错误处理 | 删除仅被测试调用、把识别错误静默转为空数组的 `detect_rect` 包装，统一使用有错误返回的 `detect_pixels`。删除运行时对翻译错误脱敏的单行转发，直接调用原有脱敏实现。 |
| 依赖 | 移除平台/UI 的直接 Base64 依赖、搜索器未使用的 Serde/JSON 依赖，以及翻译进程内结果/事件的未使用序列化派生与直接 Serde 依赖。Tokio 从 `full` 改为实际需要的特性；平台、截图和运行时统一使用工作区的 image 定义。锁文件由 Cargo 更新。 |
| 配置读取 | 合并重复 HashMap 查询，继续遵循用户配置优先、默认值回退的规则。 |

## 保留的边界

- `rotor-platform` 继续负责原生系统能力；共享业务 crates 不引入 GPUI。
- 设置的队列上限、自动合并回执、已接受写入的顺序以及快捷键 prepare/finish 协调保持原样。
- 搜索、翻译、截图及贴图的请求标识、取消和过期结果拒绝继续由原有机制处理。
- 配置和贴图记录的未知字段、原子写入、更新签名验证和原生更新失败恢复保留；模型、许可和用户资料未改动。
- `native/gpui-macos` 的本地后端仍承担窗口释放修复；`native/gpui-platform` 仍负责去除不支持的后端依赖。这些代码不能按“历史文件”直接删除。
- 工作区另有并行的 macOS 截图预绘制改动（desktop capture、platform overlay、UI capture 及 `capture_paint_smoke` 示例）。本轮未撤销或将它们计入上述清理成果；全工作区检查运行于包含这些改动的共享工作区。

## 验证

- macOS / Rust 1.97.0：工作区编译、平台 crate 独立编译、全目标严格 Clippy、格式及差异空白检查通过。最后调整图标源像素释放后，52 项 UI 测试和全目标严格 Clippy 再次通过。
- 全量测试：221 通过、0 失败、0 忽略，包括新增的通配符/Unicode/别名优先级和共享图标回归测试。首次沙箱运行无法绑定回环端口；使用独立合成资料目录并允许本地测试端口后通过。
- Windows x64 和 macOS ARM64 的原生依赖图检查通过；两个平台的共享核心依赖边界检查通过。环境没有 PowerShell，核心检查使用与仓库 PowerShell 脚本等价的 `cargo tree` 参数和禁用包匹配规则执行。
- 合成配置与贴图 `profile_roundtrip` 通过，验证未知字段、图片和几何数据保留。
- OCR release smoke 与空闲释放验证通过：正确识别合成中英文夹具的 2 个区域，并确认等待 32 秒后 OCR 模型已释放。
