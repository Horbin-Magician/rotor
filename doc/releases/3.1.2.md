# Rotor 3.1.2

[中文](#中文) · [English](#english)

## 中文

本版本汇总 `v3.1.1..c767a5e` 的变更，简化截图界面的提示与长截图切换操作。

### 改进

- 截图操作提示移至左下角，采用半透明圆角样式，并在开始框选后隐藏，减少对选区的遮挡。
- 移除独立的长截图模式切换按钮，保留 L 快捷键切换普通截图与长截图；原按钮区域可直接开始框选。

## English

This release covers changes in `v3.1.1..c767a5e`, simplifying capture hints and scrolling capture mode switching.

### Improvements

- Move capture hints to the bottom-left corner with a translucent, rounded appearance. Hide them once selection begins to reduce obstruction of the selected area.
- Remove the separate scrolling capture mode button while retaining the L shortcut to switch between normal and scrolling capture. Selection gestures can now start in the former button area.

### Release and validation scope

Target platforms are Windows x64 and macOS Apple Silicon. The release workflow produces installers, a macOS update archive, and signed update metadata.

Automated checks and real-device acceptance are recorded separately. These notes do not establish native GUI, production installation/update, or macOS signing/notarization acceptance for this version. Review release artifacts alongside CI results and actual platform acceptance.
