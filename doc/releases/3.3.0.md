# Rotor 3.3.0

[中文](#中文) · [English](#english)

## 中文

本版本新增选区屏幕录制，支持导出 MP4 视频与 GIF 动图，并改进截图轮廓识别、目录搜索性能和快捷键显示。

### 新功能

- 在截图选区中启动屏幕录制，支持暂停、继续和停止；暂停时间不计入录制时长，单次录制最长 5 分钟。
- 将录制内容导出为 MP4 视频或 GIF 动图，GIF 提供标准和高画质选项；支持查看导出进度和取消导出。
- 使用紧凑的录制控制条，并在停止后显示围绕选区居中的自适应预览面板。关闭未保存的录制时提示确认，取消导出后保留录制内容以便重试。

### 改进与修复

- 改善截图智能选区对细线轮廓和相邻边框的识别，减少轮廓丢失或错误合并。
- 每次搜索只编译一次目录匹配模式，并在相邻 NTFS 条目间复用目录匹配结果，减少目录查询的重复计算。
- 统一快捷键的修饰键顺序与按键显示，按平台显示 Cmd 或 Win，并简化字母和数字键名称。

### 发布与验证范围

目标平台为 Windows x64 和 macOS Apple Silicon。发布流程生成 Windows 安装包、macOS DMG、macOS 更新归档及签名更新清单，延续 macOS Developer ID 签名和 Apple 公证流程。

发布产物需通过流水线中的回归测试、构建、签名、公证与完整性检查。不同显示缩放比例和多显示器环境下的录制控制、预览、导出与截图选区，仍需实机交互验证。自动化检查不代表生产安装升级或完整功能的实机验收。

## English

This release adds selected-region screen recording with MP4 video and animated GIF export, and improves capture region detection, directory search performance, and shortcut labels.

### New features

- Start screen recording from a capture selection, with pause, resume, and stop controls. Paused time is excluded from the recording duration, with a maximum of five minutes per recording.
- Export recordings as MP4 videos or animated GIFs, with standard and high-quality GIF presets, export progress, and cancellation.
- Use a compact recording toolbar and an adaptive review panel centered on the selected region after recording stops. Closing an unsaved recording requires confirmation, and cancelling an export preserves the recording for another attempt.

### Improvements and fixes

- Improve smart capture region detection for thin outlines and adjacent borders, reducing missing outlines and incorrect merging.
- Compile directory matching patterns once per query and reuse directory matches across adjacent NTFS entries to reduce repeated work during directory searches.
- Normalize modifier order and shortcut labels, display Cmd or Win for the current platform, and simplify letter and digit key names.

### Release and validation scope

Target platforms are Windows x64 and macOS Apple Silicon. The release workflow produces a Windows installer, macOS DMG, macOS updater archive, and signed update metadata, retaining Developer ID signing and Apple notarization for macOS.

Release artifacts must pass the pipeline's regression tests, build, signing, notarization, and integrity checks. Recording controls, previews, exports, and capture selections at different display scales and across multiple monitors still require real-device interaction testing. Automated checks do not establish production installation/update or complete real-device functional acceptance.
