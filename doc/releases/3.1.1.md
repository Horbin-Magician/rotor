# Rotor 3.1.1

[中文](#中文) · [English](#english)

## 中文

本版本汇总 `v3.1.0..f6d7e57` 的变更，改进搜索结果、长截图、贴图窗口和安装界面。

### 新功能与改进

- 搜索结果高亮名称和路径中的匹配内容，支持名称的拼音、首字母和通配符查询。
- 调整搜索排序：移除名称完整匹配、前缀匹配和短名称的额外加分，按路径匹配层级、扩展名和使用记录排序；常用的部分匹配结果可以排在完整或前缀匹配结果之前。
- 修复 macOS 应用本地化名称解析，支持 UTF-8、UTF-16、XML 和二进制格式的 `InfoPlist.strings`，缺少显示名称时回退到 `CFBundleName`。
- 长截图由固定高度和像素数量限制改为累计 RGBA 像素缓冲区的 256 MiB 预算，允许采集更长的图片；达到预算或分配失败时保留已成功拼接的内容。大尺寸贴图采用分块显示，画布导出也按字节预算检查。该预算不代表应用总内存上限；仍仅支持单显示器内的手动纵向滚动采集。
- 拖动贴图时可吸附到附近可见贴图的边缘并对齐角点；窗口采用直角外观。
- 更新 Windows 安装程序的插图与页面文案，改进 macOS 磁盘映像布局，并柔化设置页标志的悬停光效。

### 发布与验证范围

目标平台为 Windows x64 和 macOS Apple Silicon。发布流程生成安装包、macOS 更新归档及签名更新清单。

自动化检查与实机验收分别记录。本说明不代表本版本已完成原生 GUI、跨显示器缩放、生产安装升级或 macOS 签名与公证验收；请结合 CI 结果和实际平台验收审查发布产物。

## English

This release covers changes in `v3.1.0..f6d7e57`, improving search results, scrolling capture, pinned image windows, and installers.

### Features and improvements

- Highlight matching text in search result names and paths, including pinyin, initials, and wildcard queries for names.
- Remove ranking bonuses for exact name matches, prefixes, and shorter names. Rank by path match tier, extension, and usage history; frequently used partial matches can now precede exact or prefix matches.
- Fix localized macOS application name parsing for UTF-8, UTF-16, XML, and binary `InfoPlist.strings`, falling back to `CFBundleName` when a display name is absent.
- Replace fixed scrolling capture height and pixel limits with a 256 MiB budget for the accumulated RGBA pixel buffer, allowing taller images. Preserve accepted content when the budget is reached or allocation fails. Render large pinned images in tiles and check canvas exports against a byte budget. This budget is not a limit on total application memory; capture still requires manual vertical scrolling within one display.
- Snap dragged pins to nearby visible pin edges and align corners. Use square window corners.
- Refresh Windows installer artwork and page copy, improve the macOS disk image layout, and soften the settings logo hover glow.

### Release and validation scope

Target platforms are Windows x64 and macOS Apple Silicon. The release workflow produces installers, a macOS update archive, and signed update metadata.

Automated checks and real-device acceptance are recorded separately. These notes do not establish native GUI, mixed-display scaling, production installation/update, or macOS signing/notarization acceptance for this version. Review release artifacts alongside CI results and actual platform acceptance.
