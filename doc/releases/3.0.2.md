# Rotor 3.0.2

[中文](#中文) · [English](#english)

## 中文

本版本汇总 `v3.0.1..34accc2` 的全部 43 个新增提交，包含搜索索引可靠性与性能、
截图与贴图、流式翻译与运行时稳定性，以及配置、更新器和跨平台窗口处理修复。

### 修复与改进

- 下次启动时按最小化状态恢复贴图。贴图 PNG 改为原子写入并清理残留临时文件；
  工具栏显示导出、保存、裁剪、OCR 与持久化状态及错误。
- 打开文件成功前保持搜索窗口；搜索输入不再裁切文本，并放大居中光标。
- 搜索索引原子快照隔离与校验，分页以稳定游标合并多卷结果；区分替换查询与翻页；
  处理索引不可用、并发文件编辑，以及无 USN 变更日志的 NTFS 卷。
- 解析 `~` 排除路径（含 Windows `USERPROFILE`），路径比较忽略大小写；取消刷新
  视为已释放并完成被抢占的搜索；限制恢复重扫并忽略过期监听回调。
- 框选接受细长选区，拖动时限制 Windows 光标；按显示器句柄解析截取屏幕；
  macOS 保留无标题窗口并跳过 Rotor 自身窗口；复用遮罩时刷新标题。
- 非文本选区复制后恢复剪贴板；文本标注请求实际解析到的字体族；手改的非字符串
  配置标量不再使整个配置文件失败。
- 流式 LLM 按空闲读取超时而非总时长；流式进度不阻塞工作线程；快捷键协调超时
  以免卡住配置写入；贴图持久化失败后从磁盘恢复。
- 发布版 Shell 错误写入日志文件；更新器改用单一 latest 发布清单。
- 升级 canvas resvg，并限定 macOS 更新器依赖范围。
- 删除未使用的翻译表、搜索结果图标字段，以及不会出现的更新清单字段与目标别名；
  去掉索引释放与刷新中的冗余工作，以及不可达分支和从未变化的参数。

### 性能

- 搜索先发布结果再加载有限图标批次，压缩名称并跳过 ASCII 转写，批量协调目录
  变更并压缩快照，限制待处理工作并转发取消，恢复并检查点已校验的 NTFS 索引。
- 截图减少像素拷贝并取消过期图像任务。

## English

This release covers all 43 new commits in `v3.0.1..34accc2`, including search
index reliability and performance, screenshot and pin fixes, streaming
translation and runtime stability, and corrections for configuration, the
updater, and cross-platform window handling.

### Fixes and improvements

- Restore minimized pins on the next start. Write pin PNGs atomically and sweep
  leftover temporaries. Show export, save, crop, OCR, and persistence status
  and errors in the pin toolbar.
- Keep the search window open until a file actually opens. Prevent search text
  clipping and enlarge the centered caret.
- Isolate and validate atomic search index snapshots, and merge volume pages
  with stable index cursors. Distinguish replacement queries from page
  requests. Handle unavailable indexes, concurrent file edits, and NTFS volumes
  without a USN change journal.
- Resolve `~` in excluded paths (including Windows `USERPROFILE`) and compare
  paths case-insensitively. Treat cancelled refreshes as released and finish
  pre-empted searches. Bound recovery rescans and ignore stale watcher callbacks.
- Accept thin selections and confine the Windows cursor during a drag. Resolve
  the captured monitor by handle. On macOS, keep untitled windows and skip
  Rotor's own windows. Refresh reused mask titles.
- Restore the clipboard after a non-text selection copy. Request the resolved
  font family for text annotations. Read hand-edited non-string config scalars
  instead of failing the whole file.
- Bound streamed LLM replies by idle reads rather than total time. Forward
  streaming progress without blocking worker threads. Time out shortcut
  coordination instead of stalling writes. Recover the pin store after a failed
  persistence step.
- Record shell errors in the log file in release builds. Use a single latest
  release manifest for updates.
- Upgrade canvas resvg and scope macOS updater dependencies.
- Drop the unused translation table, the unused search-result icon field, and
  updater manifest fields and targets that never occur. Remove redundant work
  from index release and refresh, plus unreachable branches and parameters that
  never varied.

### Performance

- Search publishes results before loading bounded icon batches, compact names
  and skip ASCII transliteration, reconcile directory batches and compact
  snapshots, bound pending work and forward cancellation, and resume and
  checkpoint validated NTFS indexes.
- Capture reduces pixel copies and cancels stale image work.

`Rotor_3.0.2_x64-setup.exe` and `Rotor_3.0.2_aarch64.dmg`; macOS automatic updates
