# Rotor 3.0.1

[中文](#中文) · [English](#english)

## 中文

本版本汇总 `v3.0.0..4a44d71` 的全部 19 个新增提交，包含 AI 服务商与搜索对话、
搜索索引可靠性改进，以及贴图、截图和 macOS 原生窗口修复。

### 新功能

- 新增统一 AI 服务商设置，支持 DeepSeek、OpenAI、Claude 和自定义兼容服务，
  可分别保存地址、密钥、模型及最大输出 Token 数，并测试配置。AI 翻译与搜索对话
  共用当前服务商；保留已有原生版本的配置及未知字段。
- 搜索窗口支持按 Tab 切换 AI 对话，提供 Markdown 流式回复、连续追问、复制、
  停止生成、失败重试和新对话。查询完成且无结果时，按 Enter 可转为 AI 提问；
  关闭窗口后不保存聊天记录。改善 macOS 中文输入法候选界面可见性。
- 贴图缩放时居中显示缩放百分比。

### 修复与改进

- 贴图标注可随记录保存并在重启后恢复，补充关闭时保存及恢复标注画布的测试。
- 修复贴图拖动漂移与裁剪时图像缩放变化，调整 macOS 窗口缩放期间的图层定位。
- macOS 截图遮罩先完成预绘制再显示；关闭原生窗口时正确释放渲染与辅助功能资源，
  避免反复开关窗口后 Metal 纹理和 IOSurface 持续占用内存。
- 搜索索引正确协调目录子树变更和新接入磁盘；限制文件监听事件积压，并在溢出后恢复。
- 改善磁盘扫描失败与部分索引可用状态的处理，丢弃失败构建中的不完整扫描结果，
  重置过期分页，跳过无法访问的子项，并隐藏搜索界面的索引错误提示。
- 限制翻译响应体及错误详情大小。
- 显示器枚举与截图改用 Windows/macOS 原生平台 API，移除 xcap；优化 macOS
  窗口几何读取和 BGRA 像素捕获，减少中间缓冲与通道转换。
- 精简服务与依赖，拆分设置和截图协调逻辑，共享原生图标像素并复用搜索查询缓冲。
- 替换 macOS 已弃用的 Foundation 绑定，修正原生对象桥接及 block ABI，
  增加互操作测试和 macOS CI 覆盖。
- 移除 Gitee 发布同步及更新端点，使用 GitHub 原生 stable/preview 更新源。

## English

This release covers all 19 new commits in `v3.0.0..4a44d71`, including shared AI
providers and search chat, search index reliability improvements, and fixes for
pinned images, screenshots, and native macOS windows.

### New features

- Add shared AI provider settings for DeepSeek, OpenAI, Claude, and custom
  compatible services. Save each provider's endpoint, API key, model, and maximum
  output tokens separately, and test the configuration. AI translation and search
  chat share the active provider. Existing native configuration and unknown fields
  are preserved.
- Press Tab in the search window to switch to AI chat, with streaming Markdown
  replies, follow-up questions, copying, stopping generation, retrying failures,
  and starting new conversations. Once a search finishes with no results, press
  Enter to send the query to AI. Chat history is not saved after closing the
  window. Improve Chinese IME candidate visibility on macOS.
- Show a centered zoom percentage when zooming pinned images.

### Fixes and improvements

- Persist pinned image annotations and restore them after restart. Add tests for
  saving records during shutdown and restoring annotated canvases.
- Fix pinned image drag drift and image scale changes during cropping. Adjust
  layer positioning while resizing macOS windows.
- Prepaint macOS screenshot masks before showing them. Release rendering and
  accessibility resources when native windows close, preventing Metal textures
  and IOSurfaces from retaining memory across repeated window open/close cycles.
- Reconcile directory subtree changes and newly attached volumes in the search
  index. Bound the file watcher backlog and recover after overflow.
- Improve handling of volume scan failures and partially available indexes.
  Discard incomplete scans after build failures, reset stale result pages, skip
  inaccessible children, and hide index error messages in the search UI.
- Bound translation response bodies and error details.
- Replace xcap with native Windows/macOS APIs for display enumeration and screen
  capture. Optimize macOS window geometry reads and BGRA pixel capture to reduce
  intermediate buffers and channel conversions.
- Streamline services and dependencies, separate settings and capture
  coordination, share native icon pixels, and reuse search query buffers.
- Replace deprecated macOS Foundation bindings, fix native object bridging and
  the block ABI, and add interoperability tests and macOS CI coverage.
- Remove Gitee release synchronization and update endpoints. Use the native
  stable/preview update feeds on GitHub.
