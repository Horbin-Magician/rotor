# Rotor 3.0.0

Rotor 3 is a fresh Rust + GPUI native desktop application for Windows x64 and
macOS Apple Silicon. It provides file search, screenshot annotations and pins,
OCR, translation, settings, global shortcuts and tray controls.

This release uses independent installation and data namespaces. It does not
import 2.x profiles, replace 2.x installations or implement their update protocol.
Existing data is left untouched. Native 3.x updates retain signature checking,
transactional handoff and failure recovery.

Windows: `Rotor_3.0.0_x64-setup.exe`. macOS: `Rotor_3.0.0_aarch64.dmg`;
automatic updates use `Rotor_3.0.0_aarch64.app.tar.gz`.

Review the repository's `native/validation-status.md` for the exact checks run
and outstanding manual/platform acceptance before publishing this draft.
