# Rotor 3.2.0

[中文](#中文) · [English](#english)

## 中文

本版本改善 macOS 搜索索引在空闲期间的持久化行为，支持更精细的截图选区与贴图裁剪，并简化 AI 设置入口名称。

### 改进与修复

- 修复 macOS 搜索索引释放内存后，待处理的文件变化无法及时写入索引快照的问题。后台维护会处理变化、保存快照并再次释放内存；前台命令可取消维护。
- 截图拖选和贴图边缘裁剪的最小面积统一为 16 个源图像像素，支持 1 × 16、2 × 8、4 × 4 等细小选区。截图拖选不足最小面积时仍回退到点击选择目标。
- 将设置导航中的「AI 服务商」简化为「AI」。

### 发布与验证范围

目标平台为 Windows x64 和 macOS Apple Silicon。发布流程生成 Windows 安装包、macOS DMG、macOS 更新归档及签名更新清单，延续 macOS Developer ID 签名和 Apple 公证流程。

发布产物需通过流水线中的回归测试、构建、签名、公证与完整性检查。macOS 长时间空闲后的搜索行为，以及不同显示缩放比例下的细小截图选区和贴图裁剪，仍需实机交互验证。自动化检查不代表生产安装升级或完整功能的实机验收。

## English

This release improves persistence of macOS search indexes during idle periods, enables finer capture selections and pinned-image crops, and simplifies the AI settings navigation label.

### Improvements and fixes

- Fix pending filesystem changes not being promptly saved to index snapshots after macOS search index memory is released. Background maintenance processes changes, saves snapshots, and releases memory again; foreground commands can cancel maintenance.
- Use a minimum area of 16 source-image pixels for capture drags and pinned-image edge cropping, allowing narrow selections such as 1 × 16, 2 × 8, and 4 × 4. Capture drags below the minimum area still fall back to the click target.
- Shorten the settings navigation label from “AI providers” to “AI”.

### Release and validation scope

Target platforms are Windows x64 and macOS Apple Silicon. The release workflow produces a Windows installer, macOS DMG, macOS updater archive, and signed update metadata, retaining Developer ID signing and Apple notarization for macOS.

Release artifacts must pass the pipeline's regression tests, build, signing, notarization, and integrity checks. Search behavior after extended idle periods on macOS, and small capture selections and pin crops at different display scales, still require real-device interaction testing. Automated checks do not establish production installation/update or complete real-device functional acceptance.
