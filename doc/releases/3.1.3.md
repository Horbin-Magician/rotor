# Rotor 3.1.3

[中文](#中文) · [English](#english)

## 中文

本版本完善 macOS 原生发行流程，为 Apple Silicon 安装包与自动更新归档接入 Developer ID 签名和 Apple 公证。

### 发布改进

- macOS 应用使用 Developer ID Application 证书签名，启用 Hardened Runtime 和安全时间戳。
- 应用与 DMG 自动提交 Apple 公证，并装订、验证公证票据及检查 Gatekeeper。
- macOS 自动更新归档包含已签名、已公证的应用；最终安装包和更新归档继续使用 Rotor 独立的更新签名校验。
- GitHub Actions 自动配置临时签名钥匙串并在打包后清理凭据；缺少 Apple 发布凭据时，生产打包会失败，避免生成未签名的生产发行包。

### 发布与验证范围

目标平台为 Windows x64 和 macOS Apple Silicon。发布流程生成 Windows 安装包、macOS DMG、macOS 更新归档及签名更新清单。

签名流程已通过本机及 GitHub macOS 生产候选打包验证。本版本产物仍需通过版本发布流水线中的构建、签名、公证与完整性检查；自动化检查不代表原生 GUI、生产安装升级或完整功能的实机验收。

## English

This release adds Developer ID signing and Apple notarization to native macOS distribution for Apple Silicon installers and updater archives.

### Distribution improvements

- Sign the macOS application with a Developer ID Application certificate, Hardened Runtime, and a secure timestamp.
- Automatically notarize the application and DMG, staple and validate their tickets, and assess them with Gatekeeper.
- Include the signed, notarized application in the macOS updater archive. Final installers and updater archives retain Rotor's separate update-signature verification.
- Configure a temporary signing keychain in GitHub Actions and remove credentials after packaging. Production packaging fails when Apple distribution credentials are missing instead of producing unsigned production packages.

### Release and validation scope

Target platforms are Windows x64 and macOS Apple Silicon. The release workflow produces a Windows installer, macOS DMG, macOS updater archive, and signed update metadata.

The signing workflow has passed local and GitHub macOS production-candidate validation. This version's artifacts must also pass the release pipeline's build, signing, notarization, and integrity checks. Automated checks do not establish native GUI, production installation/update, or complete real-device functional acceptance.
