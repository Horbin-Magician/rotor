# Rotor 3.1.0

[中文](#中文) · [English](#english)

## 中文

本版本汇总 `v3.0.2..82b6629` 的变更，主要新增滚动长截图，改进搜索排序、贴图标注和更新体验。

### 新功能与改进

- 新增滚动长截图：在截图界面点击「滚动截图」或按 L，框选区域后手动向下滚动；支持实时预览、固定标题栏与底栏识别、向上回滚后继续采集，以及完成和取消。再次按截图快捷键可完成采集，结果以贴图打开，支持复制、保存和标注。
- 长截图在重叠不足或尾部无法拼接时保留已成功拼接的内容，并提供继续采集或明确保留已有结果的操作。当前仅支持单显示器内的纵向拼接，不支持自动滚动；单边最大 16,384 像素，总像素最多 16 Mi。
- 搜索按完整查询和路径限定排序，优先直接父目录匹配；名称索引减少无效相关性层级扫描。
- 根据成功打开结果的频率和最近使用时间，在相同相关性层级内调整搜索顺序。设置中可清空使用记录；记录仅保存在当前配置目录，不记录查询词。
- 支持不透明遮盖、马赛克，以及选中并编辑已有标注。精简主工具栏，选中标注时显示对应编辑控件，改善单行工具栏尺寸与动画。
- 新建搜索窗口时正确激活；改善设置窗口背景拖动，固定搜索图标占位，减少加载时布局跳动；复制贴图时隐藏进度消息。
- 更新按钮显示更新状态，更新弹窗展示发布说明；错误通过简洁状态和错误码呈现，详细原因可在当前配置目录的 `rotor.log` 中查阅。
- 整理原生平台与桌面生命周期模块，共享依赖和请求协调逻辑，补充搜索、截图、翻译及更新回归检查和性能测量工具。

### 兼容性说明

编号标注与重做功能已移除，保留撤销。若使用过开发阶段的编号标注，包含 `Number` 标注的旧贴图记录无法恢复；原记录文件保留，不自动迁移或删除。

### 发布与验证范围

目标平台为 Windows x64 和 macOS Apple Silicon。发布流程生成安装包、macOS 更新归档及签名更新清单。

自动化检查与实机验收分别记录。本说明不代表当前版本已完成原生 GUI、跨显示器缩放、实际剪贴板粘贴、生产安装升级或 macOS 签名与公证验收；发布产物和平台验收仍需结合 CI 结果审查。

## English

This release covers changes in `v3.0.2..82b6629`, adding scrolling capture and improving search ranking, pinned image annotations, and updates.

### Features and improvements

- Add scrolling capture: click the scrolling capture entry or press L in the screenshot view, select a region, and scroll down manually. Live previews, fixed header/footer detection, upward scrolling recovery, finish, and cancel are supported. Press the screenshot shortcut again to finish and open the result as a pinned image for copying, saving, or annotation.
- Preserve accepted content when overlap is insufficient or the final segment cannot be stitched. Continue capture or explicitly keep the accepted result. Capture supports vertical stitching within one display, with no automatic scrolling; limits are 16,384 pixels per side and 16 Mi pixels in total.
- Rank complete search queries and path qualifiers, prioritizing direct parent directory matches. A name index skips irrelevant ranking tiers.
- Use successful result opens and recency to rank results within the same relevance tier. Clear usage records in settings. Records stay in the active profile and do not include search queries.
- Add opaque redaction, mosaics, and selection and editing of existing annotations. Simplify the main toolbar and show contextual editing controls, with improved single-row sizing and animation.
- Activate newly created search windows, improve dragging from the settings background, reserve result icon space during loading, and hide progress messages when copying pinned images.
- Show update status in the action button and release notes in the update dialog. Display concise errors with codes; detailed diagnostics remain in the active profile's `rotor.log`.
- Restructure native platform and desktop lifecycle modules, share dependencies and request coordination, and expand search, capture, translation, update regression coverage and performance tooling.

### Compatibility

Number annotations and redo have been removed; undo remains available. Pins containing the development-stage `Number` annotation format no longer restore. Original record files remain untouched, with no automatic migration or deletion.

### Release and validation scope

Target platforms are Windows x64 and macOS Apple Silicon. The release workflow produces installers, a macOS update archive, and signed update metadata.

Automated checks and real-device acceptance are recorded separately. These notes do not establish native GUI, mixed-display scaling, clipboard paste, production installation/update, or macOS signing/notarization acceptance for this version. Review release artifacts and platform acceptance alongside CI results.
